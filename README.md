# SadhuCholito-BN

A Bangla NLP dataset for the classification of Sadhu and Cholito Bengali texts using Deep Learning techniques.

---

# Dataset Overview

The dataset contains Bengali literary text samples categorized into two distinct language styles:

- Sadhu Bangla
- Cholito Bangla

An English translated version of the dataset is also included for multilingual NLP research.

---

# Dataset Files

| File Name | Description |
|---|---|
| bangla_train.csv | Bangla training dataset |
| bangla_test.csv | Bangla testing dataset |
| english_train.csv | English training dataset |
| english_test.csv | English testing dataset |

---

# Dataset Split Ratio

The dataset was divided using the following split ratio:

- 70% Training Set
- 30% Testing Set

This split was applied to both the Bangla and English datasets.

---

# Dataset Structure

| Column Name | Description |
|---|---|
| text | Bengali/English text data |
| type | Label (Sadhu or Cholito) |
| type | Book |

---

# Preprocessing Steps

- PDF-to-text conversion using OCR
- Sentence segmentation using Bangla punctuation marks
- Text cleaning and normalization
- Duplicate removal
- Label balancing
- Bangla-to-English translation
- Train-test splitting

---

# Applications

- Bangla NLP

- Bengali Literary Analysis
